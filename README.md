## 📝 Описание проекта

Информационная система для автоматизации процесса бронирования номеров в гостинице. Проект разработан в рамках учебной практики.

### 🔥 Возможности

- 🔐 **Авторизация и регистрация** пользователей
- 🛏️ **Управление номерным фондом** (CRUD)
- 📅 **Бронирование номеров** с расчётом стоимости
- 📊 **Формирование отчётов** по загрузке и доходам
- 📤 **Экспорт отчётов** в Excel и PDF
- 👤 **Разграничение прав** (Администратор / Клиент)
